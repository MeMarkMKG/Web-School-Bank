# ระบบฝาก-ถอนเงินนักเรียน

เว็บไซต์บันทึกการฝาก-ถอนเงินของนักเรียน พร้อมสรุปยอดคงเหลือรายคน ประวัติการทำรายการ
และจัดการรายชื่อนักเรียน (เพิ่ม / แก้ไขชื่อ / ลบ) ได้ตลอดเวลา
ข้อมูลถูกเก็บใน **Google Sheet** ผ่าน Apps Script Web App

## ไฟล์ในโปรเจกต์

```
index.html                     หน้าเว็บหลัก
css/styles.css                 ดีไซน์ทั้งหมด (รองรับมือถือ)
js/app.js                      ตรรกะการทำงาน + การเชื่อมต่อ API
google-apps-script/Code.gs     Backend สำหรับวางใน Google Apps Script
```

## เริ่มใช้งานเร็ว (โหมดทดลอง)

เปิด `index.html` ในเบราว์เซอร์ได้ทันที ระบบจะแสดงป้าย “โหมดทดลอง (บันทึกในเครื่อง)”
และเก็บข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น
เหมาะสำหรับลองเล่นก่อนเชื่อมต่อ Google Sheet

## เชื่อมต่อ Google Sheet (ใช้งานจริง)

1. สร้าง Google Sheet ใหม่ 1 ไฟล์ ตั้งชื่ออะไรก็ได้ เช่น `ระบบเงินนักเรียน`
2. ไปที่เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้วคัดลอกเนื้อหาไฟล์ `google-apps-script/Code.gs` วางแทน
4. กด **Deploy → New deployment**
   - Select type: **Web app**
   - Description: ตั้งชื่อตามต้องการ
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด Deploy แล้วอนุญาตสิทธิ์ (Authorize access) ตามขั้นตอนของ Google
6. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`
7. เปิดไฟล์ `js/app.js` แก้บรรทัดนี้

   ```js
   const CONFIG = {
     API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
   };
   ```

8. เปิด `index.html` ใหม่ ป้ายมุมขวาบนจะเปลี่ยนเป็น “เชื่อมต่อ Google Sheet”
   และชีต `Students` / `Transactions` จะถูกสร้างให้อัตโนมัติเมื่อทำรายการแรก

> ถ้าแก้ไขโค้ดใน Apps Script ภายหลัง ต้องกด **Deploy → Manage deployments → Edit → New version**
> แล้วกด Deploy ใหม่ URL เดิมจะยังใช้ได้

## ฟีเจอร์

- เพิ่มนักเรียนใหม่ได้ไม่จำกัด (ชื่อ + ชั้น/ห้อง + รูปภาพ)
- แก้ไขชื่อ-ชั้นห้องภายหลังได้ ประวัติเดิมจะแสดงชื่อใหม่ให้อัตโนมัติ
- ลบนักเรียนพร้อมยืนยันก่อนลบ และลบประวัติของคนนั้นทั้งหมด
- ฝาก / ถอนเงิน พร้อมหมายเหตุ (ถอนเกินยอดคงเหลือได้ ยอดจะติดลบ)
- สรุปจำนวนนักเรียน ยอดเงินคงเหลือรวม ยอดฝาก/ถอนของวันนี้
- ประวัติการทำรายการ ค้นหาตามชื่อ/หมายเหตุ และกรองตามประเภท
- รองรับหน้าจอมือถือ

## โครงสร้างข้อมูลใน Google Sheet

**Students**

| id | name | room | balance | createdAt | updatedAt | photo |
| -- | ---- | ---- | ------- | --------- | --------- | ----- |

**Transactions**

| id | studentId | studentName | type | amount | note | balanceAfter | createdAt |
| -- | --------- | ----------- | ---- | ------ | ---- | ------------ | --------- |

`type` เป็น `deposit` (ฝาก) หรือ `withdraw` (ถอน)

`photo` เก็บรูปนักเรียนเป็นข้อความ base64 (`data:image/jpeg;...`) ระบบย่อรูปเป็น
160×160 พิกเซลก่อนบันทึก จึงมีขนาดราว 5–20 KB ต่อคน (Google Sheet จำกัด 50,000 ตัวอักษรต่อเซลล์)
ชีตเก่าที่ไม่มีคอลัมน์ `photo` จะถูกเพิ่มหัวคอลัมน์ให้อัตโนมัติเมื่อเรียกใช้ครั้งแรก
ถ้าแก้ไขโค้ด Backend ต้อง Deploy เป็น New version ด้วย

## ข้อควรระวังด้านความปลอดภัย

- ลิงก์ Web App ที่ตั้งเป็น **Anyone** หมายถึงผู้ที่รู้ URL สามารถอ่าน/แก้ข้อมูลได้
  ควรใช้ภายในโรงเรียนและไม่เผยแพร่ URL สาธารณะ
- หากต้องการจำกัดสิทธิ์ผู้ใช้งานจริงจัง ควรเพิ่มระบบล็อกอิน (เช่น Google Sign-in
  หรือ PIN) ก่อนนำไปใช้กับข้อมูลจริง

## การแก้ไขข้อผิดพลาดที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
| ----- | ---------------- |
| ขึ้นป้าย “โหมดทดลอง” | ยังไม่ได้ใส่ `CONFIG.API_URL` ใน `js/app.js` หรือยังไม่ได้รีเฟรชหน้า |
| “เชื่อมต่อ Google Sheet ไม่ได้” | URL ผิด/ไม่ใช่ `/exec`, ไม่ได้ตั้งสิทธิ์เป็น Anyone หรืออินเทอร์เน็ตมีปัญหา |
| “รูปแบบข้อมูลที่ได้จากเซิร์ฟเวอร์ไม่ถูกต้อง” | Deploy ยังใช้โค้ดเวอร์ชันเก่า ให้ Deploy version ใหม่ |
